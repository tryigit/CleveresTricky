# Installer

**Bahasa:** [English](../../../system/Installer.md) | [Türkçe](../../tr/system/Installer.md) | [简体中文](../../zh-CN/system/Installer.md) | [Español](../../es/system/Installer.md) | [Deutsch](../../de/system/Installer.md) | [Русский](../../ru/system/Installer.md) | **Bahasa Indonesia** | [हिन्दी](../../hi/system/Installer.md) | [العربية](../../ar/system/Installer.md)

Menginstal full KernelSU/APatch/Magisk module untuk Android 12-17 ARM64/x86 64. KernelSU dan APatch menyediakan dukungan WebUI penuh; Magisk berjalan dalam mode headless (lihat [Dukungan Magisk](Magisk.md)). Jalur instalasi recovery ditolak.

Setiap payload memiliki SHA 256 dan runtime menolak symlink/non-regular/unexpected files. Internal hash bukan bukti publisher, sehingga release resmi memiliki `SHA256SUMS` dan GitHub signed build provenance.
